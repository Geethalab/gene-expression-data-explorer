Help

Quick guide to explore gene expression data using this tool.

🧬 About

This tool enables interactive exploration of single-cell RNA-seq data from triple-negative breast cancer samples.

🔍 How to Use

  • Use the Search tab to type a gene name (e.g., ABCB1)
  • Or go to Browse to select from the gene list

📊 What You Will See

  • Summary metrics – total cells, prevalence, mean, max expression
  • Sample table – expression across conditions
  • Expression plot – compare gene expression across conditions
  • Try example genes: ABCB1, ABCG2

⬇️ Download Data

  • Click Download CSV to export gene expression data

⚠ ️ Notes

  • Gene names are case-insensitive (abcB1 → ABCB1)
  • If a gene is not found, check spelling

💡 Tip: Try genes like ABCB1 to see strong drug-resistance patterns.
